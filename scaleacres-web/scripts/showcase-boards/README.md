# Client work showcase boards (v2)

There is one 1600 × 1000 board per client. Each board uses its own composition, chosen to suit the client's work, so no two cards repeat a template:

| Client | Composition |
| --- | --- |
| SeaBreeze Villas | Editorial collage: official La Wisteria renders with print creatives and reel covers |
| SID Realtech | Spotlit "Coming soon" launch poster, with the website and hoarding |
| Aarize | Brand identity flat-lay with a Tessoro ad |
| Intech Developers | Wall of five real reels and the "Creates Value" post |
| TRG The Mall | Diagonal split: the official mall render (the project) and the event gate (the launch) |
| JBBR Group | Luxury still life (box, brochure, key, cards) with a Kanvas reel |
| Sohom Estate | Launch-film frame (REC and timecode) with a six-scene storyboard strip |
| DTC Group | Tilted 3D social grid of creatives for Sojon, Good Earth, Skyler and Stillwaters |
| Bhatia Group | Brochure spread: tower elevation, floor-plan creative and launch ad |
| Yugen Infra | Campaign results board (15k+ leads, 37.8% qualification, 200+ plots sold) with two real campaign reels |

Design:
- **Ground:** Brand Black.
- **Grade:** cool and clean, with deep black shading.
- **Accents:** Sky, and the gradient rule above the kicker.
- **Type:** the site's existing type.

Sources:
- **Official renders:** from each client's own website; see `sources/`.
- **ScaleAcres creatives:** from `public/images/nd/…`, the Drive reels, the Aarize ad film and the covers of the ScaleAcres YouTube shorts.

To rebuild: `node board.mjs [keys]`. It reads the assets from the working folder.
