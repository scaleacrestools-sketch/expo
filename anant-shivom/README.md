Premium spiritual-consulting website for **Anant Shivom** (Vedic astrology, Vastu,
aura healing, counselling, crystals, Rudraksha, digital reports, premium packages).

## Status — Phase 1: design direction
Self-contained, high-fidelity homepage previews (fonts embedded, no external assets).

- `deliverables/home.html` — Direction v1 (bento / navy night-sky hero).

## Design system
- Palette: Ink Navy `#1A2744` · Warm Cream `#F5EFE0` · antique gold `#B0894E`
  (luxury thread) · ember `#D4691A`/`#BF5716` reserved for primary CTAs only.
- Type: Cormorant Garamond (display) + Inter (body), embedded as woff2 data URIs.
