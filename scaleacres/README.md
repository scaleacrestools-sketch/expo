# ScaleAcres — Homepage

A complete, premium, animated homepage for **ScaleAcres**, a specialist real estate
growth and branding agency.

Static HTML/CSS/JS. No build step, no framework, no runtime dependencies. Open
`index.html` or serve the folder from any static host.

```bash
# local preview
python3 -m http.server 8000    # then open http://localhost:8000

# regenerate the vector mockups
node tools/build-assets.mjs

# bundle everything into one self-contained file (dist/, git-ignored)
node tools/build-artifact.mjs
```

`tools/build-artifact.mjs` inlines the styles, scripts and all 34 referenced
mockups into a single ~393 KB HTML file — useful for sharing a preview or
dropping the page somewhere that can only host one file. Google Fonts is the
only external request it leaves.

### Swapping in real testimonial videos

`assets/js/content.js` is the single source of truth for the circular showcase.
Set `video` to an MP4 URL and fill in the real attribution:

```js
{ row: 'top', kind: 'story',
  name: 'Real Name', role: 'Managing Director', company: 'Real Company',
  project: 'Project Name', poster: 'story-01.webp', video: '/media/story-01.mp4' },
```

While `video` is `null` the modal shows a neutral "not yet connected" panel rather
than fake media. Remove the `placeholder: true` flag once an entry is verified.

### Swapping in real imagery

Every visual is currently an original vector placeholder generated by
`tools/build-assets.mjs` (run `node tools/build-assets.mjs` to regenerate). They use
only the ScaleAcres colour system and stand in for real project artwork.

When replacing with photography, export **WebP or AVIF**, keep the `width`/`height`
attributes accurate (they reserve layout space and protect CLS), and keep
`loading="lazy" decoding="async"` on everything below the fold. The hero mockups
are intentionally `loading="eager"` — the primary logo board also carries
`fetchpriority="high"` as the LCP candidate.

Card frames are sized to their artwork's aspect ratio so nothing crops awkwardly:

| Frame | Ratio |
|-------|-------|
| `.pj--flagship` | 8:5 |
| `.pj--card` | 7:5 |
| `.pj--tall` | 45:56 |
| `.pj--wide` | 10:7 |
| `.cs__frames` | 16:10 |
| `.cap__vis`, `.card__media` | 16:10 |

Match these, or adjust the ratio in `assets/css/style.css` to suit the new files.

## Brand system

Strictly three colours — no other hue appears anywhere in the stylesheet.

| Token | Value | Use |
|-------|-------|-----|
| `--navy` | `#012258` | headings, buttons, dark sections, lines |
| `--white` | `#FFFFFF` | cards, floating header, circular panel |
| `--off` | `#F5F4F3` | page background |

Derived values are all navy at reduced alpha: body copy `.73`, secondary labels
`.6`, borders `.13`, dividers `.09`. Text on dark sections is white at `.75`.

**Typography** — Manrope (Google Fonts) with Satoshi / Neue Montreal / General Sans /
Inter named ahead of it in the stack, so self-hosting any of those later is a
one-line change. The font is loaded non-render-blocking with a `<noscript>` fallback;
the intro animation starts after `document.fonts.ready` or a 900 ms timeout,
whichever comes first, so a slow font never delays the page.

To self-host instead (recommended for best CWV and no third-party request), drop the
`.woff2` files in `assets/fonts/`, add `@font-face` rules, and delete the two
`fonts.googleapis.com` `<link>` tags.

## Animation

All motion is transform/opacity only, driven by **one shared `requestAnimationFrame`
ticker** in `main.js`. Sections subscribe when they enter the viewport and
unsubscribe when they leave, so nothing off-screen consumes a frame.

| Behaviour | Implementation |
|-----------|----------------|
| Smooth scrolling | Damped wheel scrolling layered over the real scroll position, so `position: sticky`, anchors and the scrollbar all keep working. Disabled on touch (native momentum is better) and under reduced motion. |
| Page-load intro | Logo fade+scale → label → headline line by line → description → CTAs → mockups, staggered from different directions. Complete in ~1.7 s. |
| Heading reveals | Headings are measured, regrouped into visual lines, and each line is masked and slid up. Re-splits on significant resize. Tokenises after em/en dashes so long phrases don't orphan a word. |
| Word reveal | The philosophy statement fades word by word with scroll, from 16% to full navy — never below readable contrast. |
| Marquees | Groups are cloned until they cover twice the viewport, then translated with modulo wrap for a seamless loop. Pause on hover and on focus. |
| Circular showcase | Three rows at different speeds move behind a fixed white circle; a radial veil fades cards as they pass behind it. |
| Horizontal project | The section pins and translates with scroll; dragging the row drives the page scroll, so the automatic movement pauses while held. Becomes a native swipe strip on mobile. |
| Case study | Sticky left column, scroll-linked progress line, cross-fading frames tied to the active stage. |
| Growth services | The row nearest the viewport centre reveals its visual; hover overrides. |

## Accessibility

- **Reduced motion** — `prefers-reduced-motion: reduce` disables the smooth scroller,
  all reveals, marquees, parallax and the pinned horizontal section, and leaves every
  element visible and readable. Verified: zero hidden elements in that mode.
- **No JavaScript** — every "hidden until revealed" rule is gated behind a `.js`
  class set by a one-line inline script. With scripts disabled the page renders
  complete and fully readable.
- Skip link, visible focus rings, one `<h1>`, ordered headings, `alt` on all 133
  images, labelled icon buttons.
- The modal traps focus, restores it on close, and closes via the close button, a
  backdrop click, or <kbd>Esc</kbd>. Closing empties the stage, which stops and
  unloads any playing video.
- Videos are never autoplayed and carry native controls — no surprise audio.
- Touch targets are at least 44 px high; the mobile accordion drives `aria-expanded`.

## Performance

- **66 KB gzipped** for the entire site — markup, styles, scripts and all 35 vector
  mockups combined.
- 128 of 133 images are lazy-loaded; all carry intrinsic dimensions, so CLS stays at
  zero.
- No blur filters outside the modal backdrop (which only exists while the modal is
  open).
- Off-screen animation is unsubscribed rather than throttled.
- Vector placeholders are resolution-independent; when they are replaced with
  photography, use WebP/AVIF and poster stills for video.

---

## Browser support

Modern evergreen browsers. Uses `IntersectionObserver`, CSS custom properties,
`clamp()`, `aspect-ratio`, `clip-path`, `grid-template-rows: 0fr → 1fr` transitions
and `svh` units. Graceful under both no-JS and reduced-motion.
